# Application

The `app` package provides the application lifecycle: command discovery, CLI parsing, signal handling, and graceful shutdown.

## Initialization

```go
import "gitlab.com/gorib/waffle/app"

application, err := app.Init(commands, logger)
```

`Init` accepts a slice of `Command` values and a `pry.Logger`. In practice you never call this directly — it is registered via `di.Include` in your `config/di/di.go`:

```go
di.Include("gitlab.com/gorib/waffle/app")
```

which expands to:

```go
di.Wire[app.App](app.Init, di.Args(map[string]any{
    "commands": di.Tags[app.Command](app.CommandTag),
}))
```

Your `main.go` calls `config.Init()` which delegates to the generated DI container:

```go
func main() {
    application, err := config.Init()
    if err != nil {
        fmt.Printf("failed to start: %s\n", err)
        os.Exit(1)
    }
    application.RunUntilStop()
}
```

## Running the app

### RunUntilStop

```go
a.RunUntilStop()
```

The standard entry point for production. It:

1. Starts `Watch()` in a goroutine to listen for `SIGINT` and `SIGTERM`
2. Calls `Run()` to execute the requested command

### Run

```go
a.Run()
```

Parses `os.Args`, finds the matching command by name, creates a context via `NewContextWithCommand`, and calls `command.Run(ctx)`. 

If the command returns an error, it is logged via `pry.Logger` and the process exits with status 1. If no command matches, it prints usage and exits with status 2.

### Stop

```go
err := a.Stop()
```

Calls the registered closer function (if any) and returns its error. Use this for graceful shutdown of connections, channel flushes, etc.

## Graceful shutdown

`SetCloser` registers a cleanup function that returns an error. It runs when the app receives a shutdown signal via `Watch()`:

```go
a.SetCloser(func() error {
    _ = logger.Close()
    return db.Close()
})
```

In a waffle project you do not call `SetCloser` from `main.go`. It is called inside `config/diogen/di.go`, the hand-written DI adapter, using the generated `Shutdown()` function:

```go
func InitDi() (app.App, error) {
    di, err := InitApp()
    if err != nil {
        return nil, err
    }
    application := di.AppApp()
    if closable, ok := application.(app.HasCloser); ok {
        closable.SetCloser(di.Shutdown())
    }
    return application, nil
}
```

`di.Shutdown()` is generated by `diogen` and closes all registered resources (database connections, gRPC servers, etc.) in reverse dependency order. A resource is picked up automatically if its constructor returns a type that implements `io.Closer` — see [Automatic resource cleanup](../di/overview.md#automatic-resource-cleanup).

`SetCloser` takes a `func() error`. It is called by `Stop()`. Only one closer can be registered — if you need multiple cleanup steps, combine them inside a single function (the generated `Shutdown()` already does this for all `io.Closer` resources).

## Signal handling

`Watch()` blocks on `SIGINT` (Ctrl-C) and `SIGTERM` (sent by container orchestrators). When either signal arrives, it calls `Stop()`. If `Stop()` returns an error, `Watch()` will panic.

## Usage output

When invoked without arguments or with an unknown command, the app prints:

```
Usage: <binary> <command> [options]

Commands:
  grpc      Start grpc server
  http      Start web server
  migrate   Run migrations
  scribus   Start queue consumer
```

Commands are listed in alphabetical order.

## Interfaces

```go
type App interface {
    RunUntilStop()
    Run()
    Stop() error
}

type HasCloser interface {
    SetCloser(func() error)
    Closer() func() error
}
```

`*app` implements both. `HasCloser` is used by the DI container to inject the closer after all dependencies are wired.
